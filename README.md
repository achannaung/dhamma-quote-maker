# Dhamma Quote Card Maker

Burmese Dhamma quote card maker — create quote cards like the Dhamma by NCM sample posts:
quote text with Myanmar fonts/colors/word highlights, themed backgrounds, Sayadaw portrait
(upload with automatic background removal, or built-in library portraits), Sayadaw name,
channel logo, template presets, batch mode, auto-fit text, and PNG/JPG export in
1:1 / 4:5 / 9:16 / 16:9.

## Run
Open `index.html` via any static host (GitHub Pages / Vercel). All processing is client-side.

## Structure
- `index.html` — the whole app (UI + logic)
- `fonts/` — 9 built-in Myanmar fonts (subsetted WOFF2)
- `assets/` — built-in library images (Sayadaw cutouts + Dhamma by NCM channel logo)
